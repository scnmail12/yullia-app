# 한국어 스튜디오 (Korean Studio) — 앱

율리아의 한국어 수업 앱입니다. **승인된 사람만** 쓸 수 있습니다.

- 앱 주소: **https://scnmail12.github.io/yullia-app/**
- 이 공개 저장소에는 앱 화면 코드만 있습니다. 수업 내용(교재 구성, 문제)은 비공개 저장소
  `scnmail12/yullia-content` → Supabase에 있고, 로그인과 승인을 거친 사용자에게만 전달됩니다.

## 사용 방법
1. 학생에게 앱 주소를 보냅니다. 학생은 **Реєстрація**(이메일, 비밀번호, 이름)로 가입을 신청합니다.
2. 율리아 님이 앱의 **Учні(스튜디오) → Доступ**에서 **Схвалити**(승인)를 누릅니다. **Заблокувати**를 누르면 차단됩니다.
3. 승인된 학생은 로그인 후 코스, 문법, 단어장, 연습실을 씁니다. 단어장과 점수는 계정에 저장돼 기기마다 똑같이 보입니다.
4. 가장 먼저 가입한 계정이 선생님(관리자)이 됩니다.

### 휴대폰에 앱으로 설치
- **iPhone/iPad**: Safari로 열기 → 공유 → "홈 화면에 추가"
- **Android**: Chrome → ⋮ → "앱 설치"

## 구조
```
index.html   화면 틀            auth.js   로그인·승인·내용 불러오기·계정 동기화
app.js       화면 동작          practice.js  연습실 문제 유형 8가지
styles.css   디자인             config.js    Supabase 공개 주소/키 (비밀 키 아님)
sw.js        오프라인 지원       manifest.webmanifest, icons/  홈 화면 앱 설정
```
앱 파일을 수정하면 `sw.js`의 `VERSION`을 올리고 push합니다. GitHub Pages에 1~2분 뒤 반영됩니다.
